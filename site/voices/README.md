# Vozes dos personagens

Referências selecionadas do acervo de vozes utilizado pelo Logvesp,
por solicitação de Alexandre Tavares:

| Personagem | Arquivo | Sample original |
| --- | --- | --- |
| Luna | avatar-a.mp3 | GAP/voices/female/Emily.mp3 |
| Leo | avatar-b.mp3 | GAP/voices/male/Ryan.mp3 |
| Maya | avatar-c.mp3 | GAP/voices/female/Lola.mp3 |

Os arquivos foram recuperados do armazenamento de assets configurado no
Logvesp e mantidos sem alteração. Não são gravações de estudantes.
Os termos do acervo original continuam aplicáveis.

O servidor envia o sample correspondente como `ref_audio` ao Voxtral TTS.
As referências ficam fora da pasta pública. Nenhuma chave acompanha os
arquivos. `MISTRAL_API_KEY` habilita o serviço; os IDs opcionais
`SCRATCHXR_VOICE_PT`/`SCRATCHXR_VOICE_EN` substituem a referência por idioma.
